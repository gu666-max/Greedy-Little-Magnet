吸取零件和金币，在负重惯性与炸弹威胁中，把宝贝送回绿色回收站；或吸取特殊部件，把自己拼成一台废品战车。原生 HTML / CSS / Canvas / JavaScript，无需安装依赖，无外部字体、图片或网络请求。

## 三种主要模式与附加玩法

- **闯关模式**：三张不同布局和地面配色的地图，完成全部任务立即通关。时间或生命耗尽则失败，可重试；成功才解锁下一关。首页可选择已解锁关卡重玩，进度保存在本浏览器。
- **限时挑战**：首版经典回收的 60 秒赚钱挑战，已回收分数计入成绩。兼容之前的经典最高分记录。
- **生存模式**：没有结束倒计时，三格生命耗尽才结算。每 30 秒提高危险阶段，炸弹数量上限逐步增加至 24，生成间隔缩短至 1.5 秒，炸弹主动逼近速度也增加。绿色回收区仍可入账，但不保护爆炸伤害，避免无限挂机。独立记录最佳存活时间与最高入账分数。
- **废品战车（体验版）**：90 秒收集、组装与拆箱挑战。目标是本局组装 3 种部件、拆掉 3 个木箱、回收 1500 分；结束时展示完成数量。

| 闯关地图 | 时限 | 全部通关目标 |
|---|---|---|
| 初到回收场 | 90 秒 | 回收 600 分、回收 2 次 |
| 木箱仓库 | 105 秒 | 回收 1200 分、拆掉 3 个木箱 |
| 机械迷阵 | 120 秒 | 回收 1800 分、组装 3 种部件、拆掉 4 个木箱 |

当前先完成模式框架，目标和难度参数可继续依据试玩调整；不包含每日挑战。闯关、生存和附加战车玩法均可组装四种部件，限时挑战保留原有操作。

| 战车部件 | 效果 | 上限 / 代价 |
|---|---|---|
| 旋转锯片 | 围绕身体旋转，接触木箱自动切碎 | 最多 2 片，每片增加 6 重量 |
| 装甲板 | 自动挡住一次爆炸，保留生命和宝贝 | 最多 3 块，每次防护消耗 1 块，每块增加 6 重量 |
| 弹簧推进器 | Q / Shift / 冲刺按钮发动短冲刺，可在负重下逃生 | 1 件，冷却 5 秒，增加 4 重量 |
| 前置撞击头 | 贴在移动方向前方，顶碎木箱；配合弹簧冲刺击飞炸弹 | 1 件，增加 4 重量；普通移动仍需躲炸弹 |

部件在场上有彩色光圈与名称，吸取后自动安装，不占 42 件宝贝上限。回收或甩出保留装备；重开和进入下一关时清空。满配部件转成大金币。木箱和定时补充会提供更多部件。每种模式及每个关卡的最高分分开保存。

本地预览中撞击头放在出生点附近，方便试用。冲刺击飞会点燃炸弹引线，并短暂阻止吸力吸回；要继续远离炸弹。移除了长链和拖行圆球，撞击头会平滑跟随行进方向。

## 试玩

- 直接双击本目录的 `index.html`，现代 Chrome / Edge / Firefox 均可。
- 或在本目录运行 `npm start` / `node server.cjs`，访问 http://127.0.0.1:4173。
- 已占用端口时，PowerShell 可以使用 `$env:PORT=4174; node server.cjs`。服务仅监听本机。

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标移动 / WASD / 方向键 | 移动磁铁 |
| 按住鼠标左键 / 空格 | 吸取范围内物件，炸弹也会被吸来 |
| 松开鼠标左键 / 空格 | 沿移动方向甩出部分零件；静止时朝目标方向甩出 |
| 进入左下角绿色区域 | 携带价值自动入账、清空负重 |
| Esc / 暂停按钮 | 暂停或继续 |
| Q / Shift / 冲刺按钮 | 装上弹簧后发动冲刺 |
| 手机按住拖动场地 | 移动并吸取，松手甩出；也可使用吸取按钮 |

## 规则

- 限时每局 60 秒，战车挑战每局 90 秒，闯关按关卡时限，生存无时间上限，均为 3 格生命。
- 螺丝 10 分，齿轮 25 分，铁罐 40 分，金币 60 分，金色大币 120 分。
- 已回收分数永久保留到本局结束，未回收的携带价值不计入成绩。
- 宝贝越多，体积越大、速度越慢、转弯惯性越强，吸力范围也越大。最多携带 42 件。
- 松开吸力会甩出约 35% 的物件，最多 12 件。落地的零件可以重新吸取。
- 甩出的零件可以引爆炸弹、打碎木箱。木箱会掉落额外奖励；轮胎和机械不可破坏。
- 炸弹被吸动后会点燃引线，约 2.6 秒后爆炸，近身接触会提前爆炸。爆炸会扣一格生命并震落约 45% 的携带物，随后有 2 秒保护。
- 绿色回收区在生存以外的模式保护玩家；宝贝需送进绿区才会计分。
- 后半局炸弹生成速度提高。切换标签页或窗口会自动暂停，不会偷偷消耗时间。
- 个人最佳与音效开关保存在本浏览器；浏览器禁用存储时仍可游玩。

## 文件与验证

- `game-core.js`：独立游戏逻辑，可在 Node 中测试。
- `game.js`：Canvas 绘制、输入、音效、界面与本机存储。
- `styles.css` / `index.html`：响应式界面与完整开始、帮助、暂停、结算流程。
- `server.cjs`：只提供游戏文件的本地静态服务。
- `npm test`：验证计分、回收、甩出、炸弹、倒计时、暂停与碰撞等核心规则。

浏览器验收脚本为 `tests/browser.test.cjs`，需要本机已安装 Playwright 和 Chrome / Edge，且本地服务正在运行。运行 `node tests/browser.test.cjs`；可通过 `NODE_PATH` 指定已有 Playwright 的模块目录，通过 `BROWSER_EXECUTABLE` 指定浏览器路径。截图输出到 `tests/artifacts/`。

本版验证：32 项核心规则测试、23 项真实 Chrome 浏览器验收通过，包含关卡解锁/重试/下一关/全通、存活计时/暂停/纪录/主动退出、手机触屏和离线运行，浏览器脚本错误 0。
